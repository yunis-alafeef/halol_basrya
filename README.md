# حلول بصرية | Holol Basrya

موقع عربي متجاوب لوكالة متخصصة في الدعاية والإعلان واللوحات والطباعة والهدايا الدعائية. مبني بـ Next.js App Router وTypeScript وTailwind CSS وPrisma/PostgreSQL.

## الصفحات والميزات

- الصفحة الرئيسية، من نحن، الخدمات، معرض الأعمال، المدونة، وتواصل معنا.
- لوحة إدارة خاصة على /admin: تسجيل دخول آمن، إدارة الخدمات والمشاريع والمقالات، إدارة المستخدمين، ورفع الصور.
- جلسات JWT قصيرة العمر في Cookie من نوع HttpOnly وSameSite=Strict، تخزين كلمات المرور باستخدام bcrypt، والتحقق من صلاحية الحساب من قاعدة البيانات. لا يوجد تسجيل عام.
- الصور الجديدة تحفظ في Vercel Blob. تحسين الصور مفعّل عبر next/image.
- نموذج التواصل يرسل البريد عبر Resend.

## التشغيل محليًا

1. ثبّت Node.js 20 أو أحدث وPostgreSQL.
2. انسخ .env.example إلى .env واضبط DATABASE_URL وSESSION_SECRET عشوائيًا بطول 32 محرفًا على الأقل؛ يمكنك توليد السر عبر `openssl rand -base64 32`.
3. نفّذ npm install، ثم npx prisma generate، ثم npx prisma migrate deploy، ثم npm run db:seed.
4. أنشئ أول مدير: عيّن ADMIN_USERNAME وADMIN_PASSWORD (12 محرفًا على الأقل) في بيئة آمنة وشغّل npm run admin:create. لا تضع كلمة المرور في المستودع.
5. شغّل npm run dev وافتح /admin/login.

## البيئة الإنتاجية

أضف متغيرات البيئة في منصة الاستضافة: DATABASE_URL لقاعدة PostgreSQL دائمة، وSESSION_SECRET عشوائيًا بطول 32 محرفًا على الأقل، وNEXT_PUBLIC_SITE_URL لرابط الموقع. يتطلب تشغيل لوحة الإدارة وجود قاعدة البيانات والسر. أضف BLOB_READ_WRITE_TOKEN لرفع الصور وRESEND_API_KEY وRESEND_FROM_EMAIL (مرسل موثق في Resend) وCONTACT_TO_EMAIL لإرسال البريد؛ هاتان الميزتان اختياريتان. تُحفظ تغييرات المخطط كملفات migration في prisma/migrations؛ طبّقها على قاعدة الإنتاج عبر npm run db:migrate قبل الإطلاق، وأنشئ أول مدير عبر npm run admin:create باستخدام بيانات اعتماد محفوظة بأمان. لا تعتمد على تخزين ملفات محلي في Vercel.

## Vercel والنشر التلقائي

للنشر، استورد المستودع من Vercel عبر Add New Project ثم Import Git Repository؛ سيتعرف Vercel تلقائيًا على Next.js ويستخدم أمر البناء npm run build. رفع هذا البرانش ينشئ عادةً نشر معاينة (Preview)، ولا يدمجه في main. عيّن متغيرات الإنتاج والمعاينة المطلوبة في إعدادات المشروع، وطبّق migrations على قاعدة البيانات قبل توجيه الزيارات إلى النشر. لا يتضمن المستودع إعدادًا أو أسرارًا لربط مشروع Vercel تلقائيًا؛ يجب إنشاء المشروع وإضافة متغيراته من لوحة Vercel.

## أوامر مفيدة

- npm run dev — تشغيل التطوير
- npm run build — بناء الإنتاج
- npm run lint — فحص ESLint
- npm run db:push — مزامنة مخطط Prisma للتطوير فقط
- npm run db:migrate — تطبيق migrations المحفوظة
- npm run db:seed — إضافة محتوى تجريبي أولي
- npm run admin:create — إنشاء حساب مدير أولي بأمان

## ملاحظات أمنية

لا ترفع ملفات .env. احفظ الأسرار في متغيرات البيئة. أنشئ كلمة مرور قوية وفريدة لحساب المدير، واضبط SESSION_SECRET عشوائيًا. يحد التطبيق من أنواع الملفات وحجمها في رفع الصور. حماية محاولات الدخول داخل ذاكرة العملية مساعدة فقط؛ استخدم WAF أو خدمة تحديد معدل الطلبات لحماية أقوى في الإنتاج. بيانات المشاريع والمقالات في seed أمثلة قابلة للاستبدال من لوحة الإدارة.
